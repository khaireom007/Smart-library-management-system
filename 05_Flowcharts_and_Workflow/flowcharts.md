# 05. Flowcharts and Workflow

The Mermaid source in `flowcharts.mmd` contains flowcharts for the main menu and each major operation. Terminals use rounded shapes, input/output uses parallelograms, processing uses rectangles, and decisions use diamonds. Render the `.mmd` file in a Mermaid-compatible viewer to view the diagrams.

## Included diagrams
1. Main menu and exit
2. Add a book
3. Search by title
4. Display all records
5. Update a book
6. Remove duplicate categories
7. Count available books
8. Find by author
9. Sort titles
10. Display available books
11. Borrow or return a book

These diagrams describe the same decisions and loops implemented in `07_Python_Programming/main.py`.
