## Introduction
A library maintains information about books, authors, categories, ISBN numbers, prices, and whether each book is available. This project develops a console-based Smart Library Management System using Python's built-in data structures.

## Background of the Problem
A program that uses separate variables for each book is difficult to maintain as the collection grows. The Unit 2 assignment extends a basic library program so it can manage multiple records and demonstrate Strings, Lists, Tuples, Sets, and Dictionaries.

## Problem Statement
Develop a Python program that stores and manages a collection of book records. The system must support adding, searching, updating, and displaying books; identifying available books; finding books by author; counting available books; sorting titles; and identifying unique categories. It must demonstrate appropriate selection and use of all five built-in data structures.

## Why the System Is Required
A structured collection makes related information easier to store, search, update, and report. The project also provides practical experience with data organization, loops, conditions, methods, validation, and systematic testing.

## Objectives
1. Store each complete book record in a dictionary.
2. Store the catalogue as a list of dictionaries.
3. Use strings for textual fields and string processing.
4. Use a tuple for fixed ISBN components.
5. Use sets to identify unique categories and authors.
6. Search, update, and display records.
7. Demonstrate list, tuple, set, string, and dictionary operations.
8. Test normal, boundary, duplicate, and invalid-input cases.

## Project Scope
This is a beginner-level, console-based prototype. Data is held in memory during execution and is not saved after the program closes. It does not include a GUI, web interface, database, authentication, or network access.
