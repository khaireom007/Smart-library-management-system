**Project:** Smart Library Management System – Data Structures and Collection Management using Python

This project follows the uploaded Unit 2 assignment. It demonstrates Python strings, lists, tuples, sets, and dictionaries through a console-based library catalogue.

## Run the application
Open a terminal in `07_Python_Programming` and run:

```bash
python main.py
```

Python 3.8 or later is recommended. No third-party packages are required.

## Run automated tests
From `07_Python_Programming`, run:

```bash
python -m unittest discover -s ../08_Program_Testing -v
```

## Implemented Features
Add, display, search, and update books; search by author; list available books; count availability; list unique categories/authors; sort titles; borrow/return books; and demonstrate all five built-in data structures.
