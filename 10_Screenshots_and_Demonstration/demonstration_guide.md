# 10. Screenshots and Demonstration Guide

## Before the Demonstration
1. Extract the project ZIP.
2. Open a terminal in `07_Python_Programming`.
3. Run `python main.py`.
4. Keep the terminal readable and avoid showing unrelated personal information.

## Suggested Demonstration Sequence
1. **Main menu:** show the menu on program start.
2. **Display all books:** select option 2.
3. **Search:** select option 3 and enter `dune` to demonstrate case-insensitive search.
4. **Available books:** select option 6.
5. **Count:** select option 7; sample catalogue reports two available books.
6. **Unique categories/authors:** select options 8 and 9.
7. **Add book:** select option 1 and enter valid data including a 13-digit ISBN.
8. **Duplicate ID:** attempt to add an existing ID and capture the rejection.
9. **Borrow/return:** use option 11 to change availability and show the count changing.
10. **Data-structure demonstrations:** select option 12.
11. **Exit:** select option 0.
