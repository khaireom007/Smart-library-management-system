## Concepts Learned
Through this project, I can explain how strings, lists, tuples, sets, and dictionaries serve different purposes. A dictionary groups the fields of one book, a list holds the catalogue, a tuple stores fixed ISBN components, and a set helps identify unique categories and authors. String methods help normalize and compare user input.
